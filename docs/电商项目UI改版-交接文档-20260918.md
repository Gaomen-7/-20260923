## 八、注意事项

1. **git 代理**：系统环境变量 `ALL_PROXY=http://127.0.0.1:7897` 可能导致 git 连接失败，执行 git 前在当前会话清除（`$env:ALL_PROXY=""`），**不要永久删除用户的系统环境变量**
2. **Python 路径**：系统 `python` 指向沙箱 Python（无 playwright），完整路径 `F:\Python\python.exe` 才有 playwright；运行 doubao-ui-design 脚本需用 `& "F:\Python\python.exe"`
3. **GitHub 中文仓库名**：GitHub API 对中文字符会过滤，创建带中文的仓库名时实际名称可能不同
4. **PowerShell git 退出码**：PowerShell 可能把 git 的 stderr 进度输出误判为 exit code 1，实际操作可能已成功，需看输出内容判断
5. **前端 Node 版本**：webpack3 项目需用 Node 10-12.x，高版本 Node 可能编译失败
6. **本目录已有文件**：`商城项目交接文档.md`、`第二阶段-电商数据分析交接文档.md` 为原始交接文档；`mall-architecture.html`、`mall-architecture.candidate.json`、`电商项目架构设计.zip` 为架构设计相关文件，均不要覆盖
