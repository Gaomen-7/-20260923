## 三、商品发布流程（核心，五步完整原型已确认）

### 流程步骤

```
第一步 基本信息 (PublishBaseInfo)
  │  填写：商品名称/描述/三级分类级联/品牌(按分类动态查询)/重量/积分/主图/图集
  │  保存：POST /PublishGoods/saveGoodsBaseInfo → Redis key={pubKey}-base
  │  跳转：$router.push({name:'setGoodsAttr', params:{categoryId}})
  ▼
第二步 规格参数 (SetGoodsAttr, attrType=1)
  │  加载：GET /GoodsAttr/listByCategory/{categoryId}/1
  │  渲染：value_type=1→输入框/下拉；value_type=2→标签(tag)多选可删除
  │  保存：POST /PublishGoods/saveGoodsAttrValues → Redis key={pubKey}-goods-attr
  │  跳转：$router.push({name:'setSaleAttr', params:{categoryId}})
  ▼
第三步 销售属性 (SetSaleAttr, attrType=2)
  │  加载：GET /GoodsAttr/listByCategory/{categoryId}/2
  │  渲染：每行=属性名+复选框组(标准值)+"+自定义"按钮
  │  自定义：点击+自定义可添加标准模板外的新值(如红色)，自动选中
  │  规则：选中什么提交什么，不强制必选
  │  保存：POST /PublishGoods/saveSaleAttrValues → Redis key={pubKey}-sale-attr
  │  跳转：$router.push({name:'setSku', params:{pubKey}})
  ▼
第四步 SKU设置 (SetSku.vue)
  │  从 Redis 读取 sale-attr，对选中的销售属性值做笛卡尔积生成 SKU 行
  │  表格：复选框(启用/禁用)+动态属性列+商品名称+标题+副标题+价格+展开按钮(>)
  │  展开面板(ElementUI Collapse)：SKU图片选择、折扣、满减
  │  保存：POST /PublishGoods/saveSkuCache → Redis key={pubKey}-sku
  │  跳转：$router.push({name:'publishComplete', params:{pubKey}})
  ▼
第五步 保存完成 (PublishComplete.vue)
  │  POST /PublishGoods/saveComplete → persistAll（5表写入@Transactional）→ clearCache
  │  显示 goodsId，提供"查看商品列表"和"继续发布商品"按钮
```

### 步骤条 active 值（0-indexed）

| 页面 | active 值 |
|---|---|
| PublishBaseInfo（第一步） | 0 |
| SetGoodsAttr（第二步） | 1 |
| SetSaleAttr（第三步） | 2 |
| SetSku（第四步） | 3 |
| 保存完成（第五步） | 4 |

### Redis 缓存设计

1. 四步数据均存入 Redis，key 前缀 `{pubKey}`，后缀 `-base` / `-goods-attr` / `-sale-attr` / `-sku`
2. 发布完成后 persistAll 持久化到数据库，clearCache 清理该 pubKey 的所有缓存
3. clearCache 在 saveComplete 的 finally 块中执行，确保即使 persistAll 失败也清理缓存
