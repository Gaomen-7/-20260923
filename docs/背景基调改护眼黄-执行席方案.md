# 执行席方案 — 背景基调改为护眼黄/浅棕色

> 生成时间：2026-09-17
> 指挥席：Doubao
> 前置状态：左侧导航 + 多巴胺配色改版已执行完毕
> 改动范围：仅修改 CSS 颜色变量，**零结构改动**

---

## 一、改动概述

将页面背景从当前的**冷白/浅灰**基调改为**护眼黄/浅棕色**暖调基调，降低长时间使用的视觉疲劳。仅修改 3 个 CSS 变量，所有布局、组件、交互逻辑不变。

### 改动前（当前）
```css
--canvas:  #F5F3EF;  /* 页面底：冷调浅灰 */
--panel:   #FFFFFF;   /* 卡片/侧栏底：纯白 */
--panel-2: #FAF8F5;   /* 内嵌底：冷白 */
```

### 改动后（推荐方案：护眼黄系）
```css
--canvas:  #FFF4D6;  /* 页面底：护眼暖黄 */
--panel:   #FFFCF0;  /* 卡片/侧栏底：浅奶黄 */
--panel-2: #FBEEC2;  /* 内嵌底（搜索框/表头）：稍深暖黄 */
```

---

## 二、三套配色方案（选一套执行）

### 方案 A：护眼黄系（推荐，最经典的护眼色）

| 变量 | 色值 | 用途 | 预览 |
|------|------|------|------|
| `--canvas` | `#FFF4D6` | 页面底色 | 暖黄，类似护眼模式 |
| `--panel` | `#FFFCF0` | 卡片/侧栏底 | 浅奶黄，比底色亮 |
| `--panel-2` | `#FBEEC2` | 搜索框/表头等内嵌 | 稍深暖黄，形成层次 |

**特点**：最接近系统"护眼模式"的黄色调，温暖不刺眼，长时间阅读舒适。

---

### 方案 B：浅棕米色系（偏复古/纸质感）

| 变量 | 色值 | 用途 |
|------|------|------|
| `--canvas` | `#F2EAD3` | 页面底色：浅棕米 |
| `--panel` | `#FAF5E8` | 卡片/侧栏底：米白 |
| `--panel-2` | `#E8DEC0` | 内嵌底：稍深棕米 |

**特点**：类似牛皮纸/旧书页的暖棕调，质感强，与多巴胺配色形成复古撞色。

---

### 方案 C：暖杏色（介于黄和棕之间，最柔和）

| 变量 | 色值 | 用途 |
|------|------|------|
| `--canvas` | `#F7EEDD` | 页面底色：暖杏 |
| `--panel` | `#FCF7EE` | 卡片/侧栏底：浅杏白 |
| `--panel-2` | `#F0E4CC` | 内嵌底：稍深杏 |

**特点**：黄中带粉的暖杏色，比纯黄更柔和，比纯棕更明亮，中性偏暖。

---

## 三、涉及文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `src/App.vue` | 修改 3 行 | `<style>` 中 `:root` 的 3 个颜色变量 |

> **不需要修改任何其他文件**。所有子组件、布局、图标、文字颜色均不受影响，因为它们都引用这 3 个变量。

---

## 四、具体改动

打开 `src/App.vue`，找到 `<style>` 中的 `:root` 块，将以下 3 行：

```css
--canvas:#F5F3EF;
--panel:#FFFFFF;
--panel-2:#FAF8F5;
```

替换为（以方案 A 为例）：

```css
--canvas:#FFF4D6;
--panel:#FFFCF0;
--panel-2:#FBEEC2;
```

**仅此而已。** 保存后热更新自动生效。

---

## 五、执行步骤

1. 打开 `src/App.vue`
2. 定位到 `<style>` 标签内的 `:root{...}` 块
3. 修改 `--canvas`、`--panel`、`--panel-2` 三个变量的值（按选定方案）
4. 保存文件，webpack 热更新自动刷新浏览器
5. 检查：页面底色、卡片底色、搜索框底色均变为暖黄/浅棕

---

## 六、验收标准

| 检查项 | 标准 |
|--------|------|
| 页面底色 | 非纯白，呈现护眼黄/浅棕暖调 |
| 卡片/侧栏底色 | 比页面底色稍浅，形成层次 |
| 搜索框/表头底色 | 比卡片底色稍深，可辨识 |
| 文字可读性 | 深色文字在暖黄底上对比度 ≥ 4.5:1（无障碍标准） |
| 导航当前态 | 深蓝 `#1E3A8A` 在暖黄底上对比鲜明 |
| 多巴胺图标 | 多彩图标在暖黄底上不发灰、不冲突 |
| 无结构变化 | 布局、间距、圆角、交互均与改版后一致 |

---

## 七、注意事项

1. **只改 3 个变量**：不要改 `--ink`、`--muted`、`--accent`、`--line` 等其他变量，它们在暖黄底上已经过验证。
2. **`--line` 保持不变**：`rgba(26,26,46,.07)` 的发丝线在暖黄底上仍然清晰，不需要调整。
3. **如果觉得太黄**：可在 `--canvas` 中加一点灰，如 `#F8F0D8`（黄灰混合），降低饱和度。
4. **如果觉得太暗**：可将 `--panel` 调亮到 `#FFFEF7`，接近白但带暖调。
5. **回滚**：如需恢复原配色，将 3 个变量改回 `#F5F3EF` / `#FFFFFF` / `#FAF8F5` 即可。

---

## 八、推荐

**默认执行方案 A（护眼黄系）**，理由：
- 最接近用户认知中的"护眼模式"，预期一致
- 与多巴胺配色（高饱和多彩）形成"暖底+艳色"的经典搭配
- 黄色调比棕色调更明亮，B 端后台信息密度高时不压抑
