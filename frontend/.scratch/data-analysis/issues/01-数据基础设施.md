## 交付物

### 1. Java 数据生成器 `DataGenerator.java`

位置：`com.gec.generator.DataGenerator`（新建 `generator` 包）

输出 4 个文件到 `D:/haida/space/phase2-data/`：

| 文件 | 行数 | 分隔符 | 编码 |
|---|---|---|---|
| `user_behavior.log` | 100,000 | \t | UTF-8 |
| `order_data.csv` | 10,000 | , | UTF-8 |
| `review_data.csv` | 5,000 | , | UTF-8 |
| `chat_data.csv` | 2,000 | , | UTF-8 |

**行为日志字段**（12 列，匹配样本）：
`log_id, user_id, product_id, behavior_type, source, search_keyword, session_id, device_type, ip_city, product_price, quantity, behavior_time`
- behavior_type：浏览/搜索/收藏/加入购物车/购买/支付/退出（7 类，权重递减）
- source：首页推荐/站内搜索/搜索页/详情页/购物车/直播带货/广告落地页/商品详情分享/分类页/活动页
- device_type：Android/iOS/Web/平板
- ip_city：北京/上海/广州/深圳/杭州/成都/武汉/西安
- behavior_time：2026-09-01 至 2026-09-14 随机分布，高峰 10-12 点、20-23 点

**订单数据字段**（19 列）：
`order_id, user_id, product_id, category_id, order_status, pay_status, order_amount, discount_amount, actual_amount, pay_method, order_source, create_time, pay_time, ship_time, finish_time, is_return, return_status, return_reason, return_time`
- order_status：待支付/已支付/已发货/已完成/已取消/已退款（6 类）
- pay_method：微信/支付宝/银行卡/货到付款
- order_source：APP/小程序/PC/H5
- is_return=1 时 return_status 为 申请中/审核通过/已退换/驳回，return_reason 为 质量问题/尺寸不符/不想要/物流损坏/其他

**评价数据字段**（13 列，匹配样本）：
`review_id, order_id, user_id, product_id, rating, review_content, review_time, is_append, append_content, image_count, praise_num, merchant_reply, merchant_reply_time`
- rating：1-5 随机（好评 4-5 占 70%，中评 3 占 15%，差评 1-2 占 15%）
- review_content：从预设模板池随机选取（质量好/物流快/服务差/尺码问题等 20+ 模板）
- is_append：是/否，为"是"时 append_content 有内容

**交流数据字段**（14 列）：
`chat_id, user_id, product_id, category_id, session_id, chat_type, user_msg_count, merchant_reply_count, first_response_sec, session_duration_sec, is_converted, convert_action, chat_start_time, chat_end_time`
- chat_type：商品咨询/价格活动/物流查询/售后问题/投诉建议/其他（6 类，关键词匹配生成）
- is_converted：0/1，为 1 时 convert_action 为 加购/下单

### 2. Hive 建表脚本 `phase2_create_tables.hql`

位置：`E:\space\Project\test\mall-sys\phase2_create_tables.hql`

**ODS 层（4 张，外部表，SERDE 匹配文件格式）**：
- `ods_user_behavior`：行为日志，ROW FORMAT DELIMITED FIELDS TERMINATED BY '\t'
- `ods_order_data`：订单数据，CSV 格式
- `ods_review_data`：评价数据，CSV 格式
- `ods_chat_data`：交流数据，CSV 格式

**ADS 层（4 张宽表，ORC 或 TEXTFILE）**：
- `ads_user_behavior`：用户行为指标宽表
- `ads_order_analysis`：订单销售指标宽表
- `ads_review_analysis`：评价舆情指标宽表
- `ads_chat_analysis`：客服咨询指标宽表

> ADS 表结构在工单 02-05 中逐步确定，本工单先建 ODS 表 + ADS 表占位（字段在清洗 SQL 中 ALTER 或直接在清洗脚本中 CREATE TABLE AS SELECT）。

### 3. MySQL 建表脚本 `phase2_mysql_tables.sql`

位置：`E:\space\Project\test\mall-sys\phase2_mysql_tables.sql`

4 张宽表，表名前缀 `ads_`，字段与 Hive ADS 层对应，引擎 InnoDB，字符集 utf8mb4。

## 验收标准

1. `mvn compile` 通过
2. 运行 `DataGenerator.main()` 后，`D:/haida/space/phase2-data/` 下生成 4 个文件，行数符合要求
3. 行为日志文件用 `head -5` 可正常显示中文（UTF-8）
4. Hive 建表脚本语法正确（可用 `hive -f` 执行，或至少通过语法检查）
5. MySQL 建表脚本可在 `project20206` 库执行成功

## 给执行席的指令要点

- 生成器用 `java.util.Random` + 预设模板数组，不要用第三方库
- CSV 文件含中文逗号的字段用双引号包裹（评价内容、退换货原因）
- 时间格式统一 `yyyy-MM-dd HH:mm:ss`
- 主类加 `public static void main(String[] args)`，可直接右键运行
