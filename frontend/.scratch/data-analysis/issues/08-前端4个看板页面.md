## 交付物

### 2. 页面组件（4 个）

位置：`D:\vue-space\mypro5\src\components\analysis\`（新建目录）

**BehaviorAnalysis.vue**（路由 `/analysis/behavior`）：
- 顶部：日期筛选（el-date-picker 范围选择）
- 行1：流量入口饼图（ECharts pie）+ 入口转化率柱状图（bar）
- 行2：行为趋势折线图（line，多系列：浏览/搜索/加购/下单）
- 行3：转化漏斗图（funnel，ECharts 内置）
- 行4：时段热力图（heatmap，24小时 × 7天 或单天24小时柱状）
- 行5：热搜关键词表格 + 热门商品表格（el-table，分页）

**OrderAnalysis.vue**（路由 `/analysis/order`）：
- 顶部：日期筛选
- 行1：4 个指标卡片（成交金额/订单数/客单价/退换货率，el-card + 大数字）
- 行2：销售趋势折线图（金额+订单数双Y轴）
- 行3：品类销售饼图 + 退换货原因饼图
- 行4：退换货率柱状图（按品类）+ 客单价直方图
- 行5：时段销售柱状图

**ReviewAnalysis.vue**（路由 `/analysis/review`）：
- 顶部：日期筛选
- 行1：3 个指标卡片（总评价数/好评率/差评率）
- 行2：评价等级饼图 + 品类口碑对比柱状图
- 行3：关键词词云（用 ECharts wordCloud 或第三方 vue-wordcloud，若安装困难则用标签云 el-tag 模拟）
- 行4：口碑趋势折线图（好评率随时间变化）
- 行5：商品口碑榜表格（TOP20 高口碑 + BOTTOM20 低分，Tab 切换）

**ChatAnalysis.vue**（路由 `/analysis/chat`）：
- 顶部：日期筛选
- 行1：3 个指标卡片（有效会话数/平均响应时长/问题解决率）
- 行2：咨询类型饼图 + 咨询转化柱状图
- 行3：时段热力图
- 行4：热门咨询商品表格

## 验收标准

1. `npm run build` 通过
2. 4 个页面均可正常访问，图表有数据（非空）
3. 日期筛选切换后图表重新加载
4. 图表响应窗口 resize（window resize 时图表自适应）
5. 导航栏菜单正确展开/收起
6. webpack3 兼容：不使用 `?.` 可选链，用 `&&` 代替

## 给执行席的指令要点

- ECharts 用 4.x 版本（5.x 对 webpack3 不友好），`npm install echarts@4.9.0`
- 图表容器用固定高度（如 300px/400px），避免高度为 0
- 词云如果 echarts-wordcloud 安装失败，用 el-tag 大小不同的标签模拟
- 指标卡片用 el-card + 大字号数字 + 副标题，参考 Dashboard.vue 风格
- 所有 API 调用用 `this.$api.xxx` 或直接 import，与现有项目风格一致
- 页面布局用 el-row + el-col，24 栅格系统
