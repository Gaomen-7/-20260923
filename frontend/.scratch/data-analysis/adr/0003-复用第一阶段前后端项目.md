# 复用第一阶段前后端项目承载第二阶段

第二阶段的 SpringBoot 后端和 Vue 前端均复用第一阶段已有的 `mall-sys` 和 `mypro5` 项目，在其中新增分析模块，而非新建独立项目。

## 考虑过的选项

- **新建独立 data-analysis 项目**：前后端各搭一套骨架，配置 MySQL 连接、R 封装、路由、导航栏。工作量大，且与第一阶段技术栈完全重叠，拒绝。
- **仅复用后端、前端新建**：前端仍需重新搭建 ElementUI + ECharts + 路由 + 布局，收益低，拒绝。

## 决策

1. 后端在 `mall-sys` 中新增 `controller/analysis/` 包，复用现有 R 响应封装、MySQL 数据源、全局异常处理
2. 前端在 `mypro5` 中新增 4 个分析页面组件 + 路由 + 导航栏入口，复用 ElementUI、axios 封装、现有布局
3. 第二阶段 MySQL 表与第一阶段业务表共存于同一数据库 `project20206`，表名前缀 `ads_` 区分

## 后果

- 后端启动一个 MallAPP 即可同时服务商城后台和数据分析看板
- 前端导航栏需新增"数据分析"一级菜单，下挂 4 个子页面
- 两个阶段的代码在同一仓库，需注意包名和组件名不冲突
