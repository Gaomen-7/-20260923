## 二、关键设计决策

### 2.1 ECharts 版本

- **继续使用 echarts@5.4.3**（项目已锁定，Dashboard.vue 已正常运行）
- 工单08建议4.x，但5.4.3已验证兼容webpack3，无需降级
- **不安装 echarts-wordcloud**：词云用 el-tag 大小不同的标签模拟，避免额外依赖和webpack3兼容性风险

### 2.2 导航栏风格

- 现有导航栏是**横向 table 平铺布局**（`<td>` + P值高亮），**不支持下拉子菜单**
- 方案：4 个分析页面直接平铺为 4 个菜单项（P=21/22/23/24），与现有风格一致
- 菜单文字：用户行为 / 订单分析 / 评价分析 / 客服交流
- 不改造为 el-menu 下拉（改动大，可能影响现有15个菜单项）

### 2.3 路由懒加载

- 4 个分析页面均含 ECharts，使用懒加载 `component: () => import('@/components/analysis/xxx.vue')`
- 与 Dashboard.vue 的懒加载方式一致，避免打入首屏 bundle

### 2.4 日期筛选

- 每个页面顶部放 `el-date-picker` 范围选择器（type="daterange"）
- 选择后触发 `loadAll()` 重新加载所有图表
- 默认不选日期（查全部数据），日期格式 `yyyy-MM-dd`
- 用 `value-format="yyyy-MM-dd"` 直接得到字符串，传给后端 startDate/endDate

### 2.5 图表生命周期

- `mounted()` → `this.$nextTick(() => { this.initCharts(); this.loadAll(); })`
- `window.addEventListener('resize', this.resizeCharts)`
- `beforeDestroy()` → 每个 chart.dispose() + removeEventListener
- 图表容器固定高度：饼图/柱状图 300px，折线图/热力图 350px

### 5.2 热力图数据转换（通用函数）

ADS 表 hour 维度返回格式：`[{stat_date, dimension_type, dimension_value(小时), pv, ...}]`

ECharts heatmap 需要：`[[hourIndex, dayIndex, value], ...]` + xAxis(小时) + yAxis(日期)

```javascript
convertHeatmapData(rawData, valueField) {
  var hours = []
  for (var i = 0; i < 24; i++) hours.push(i + '时')
  var days = []
  var dayMap = {}
  rawData.forEach(function(item) {
    if (!dayMap[item.stat_date]) {
      dayMap[item.stat_date] = days.length
      days.push(item.stat_date)
    }
  })
  var data = []
  rawData.forEach(function(item) {
    var h = parseInt(item.dimension_value)
    var d = dayMap[item.stat_date]
    var v = Number(item[valueField]) || 0
    data.push([h, d, v])
  })
  return { hours: hours, days: days, data: data }
}
```

### 5.3 多系列折线图数据转换（通用函数）

```javascript
convertMultiLineData(rawData, seriesField, valueField) {
  var dates = []
  var dateMap = {}
  var seriesMap = {}
  rawData.forEach(function(item) {
    if (!dateMap[item.stat_date]) {
      dateMap[item.stat_date] = dates.length
      dates.push(item.stat_date)
    }
    var sName = item[seriesField]
    if (!seriesMap[sName]) seriesMap[sName] = new Array(dates.length).fill(0)
    seriesMap[sName][dateMap[item.stat_date]] = Number(item[valueField]) || 0
  })
  var series = []
  for (var name in seriesMap) {
    series.push({ name: name, type: 'line', smooth: true, data: seriesMap[name] })
  }
  return { dates: dates, series: series }
}
```

## 八、踩坑预防

1. **echarts.init 容器高度为0**：图表容器必须设固定高度（`.chart-box { height: 300px }`），否则 init 后图表不可见
2. **懒加载 + echarts**：页面懒加载后，echarts 已在全局 import，不会重复打包。但需确认 `import * as echarts from 'echarts'` 在每个页面单独 import
3. **日期范围空值**：`dateRange` 初始为 `[]`，`getParams()` 中判断 `length === 2` 才传参，避免传 undefined
4. **热力图数据稀疏**：14天×24小时=336个格子，但实际数据可能有缺失（某些小时无数据）。ECharts heatmap 对缺失格子显示为空白，可接受。或用 `visualMap` 设置 min=0
5. **后端返回字段名驼峰**：MyBatis-Plus 默认驼峰映射，实体类 `statDate` 对应数据库 `stat_date`，但 JSON 序列化后字段名是 `statDate`（驼峰）。前端取数据用 `item.statDate`，不是 `item.stat_date`
6. **el-table 数据为空**：接口返回 `resp.data` 可能是数组，用 `resp.data || []` 兜底
7. **图表 dispose**：`beforeDestroy` 中必须 dispose 所有 chart 实例，否则切换页面后内存泄漏，且再次 init 同 ID 容器可能报错
8. **window resize 监听移除**：`beforeDestroy` 中 `removeEventListener`，否则页面销毁后回调仍执行，访问已 dispose 的 chart 会报错
9. **词云 el-tag 颜色**：好评关键词用 `type="success"` 或绿色系，差评用 `type="danger"` 或红色系。字号用 `:style="{fontSize: size + 'px'}"`
10. **导航栏 P 值冲突**：新增 P=21-24，不与现有 P=1-20 冲突。localStorage 中保存的 P 值不会影响新页面
