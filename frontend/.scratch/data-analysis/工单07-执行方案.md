## 二、设计约束（继承自现有项目风格）

1. **不新建 Service 层**：Controller 直接 @Autowired Mapper，与工单07指令一致
2. **统一返回 R**：`R.ok().put("data", result)`，复用 `com.gec.controller.R`
3. **Controller 继承 BaseController**：含 `@ExceptionHandler(Exception.class)` 统一异常处理
4. **日期参数**：`@RequestParam(required = false) String startDate/endDate`，默认查全部
5. **榜单参数**：`@RequestParam(required = false, defaultValue = "10") Integer limit`
6. **接口前缀**：`/analysis/`，与第一阶段业务接口区分
7. **实体类**：用 MyBatis-Plus 注解（@TableName / @TableId / @TableField），字段与 MySQL 表一一对应
8. **Mapper**：继承 `BaseMapper<T>`，自定义查询写在 XML 中
9. **XML 路径**：`resources/mappers/analysis/`，需确认 `application.yml` 的 `mapper-locations` 已包含 `classpath*:mappers/**/*.xml`（当前配置为 `classpath:mappers/*.xml`，**需修改为 `classpath:mappers/**/*.xml` 以支持子目录**）

## 四、Controller 端点详细设计（23 端点）

### 4.1 BehaviorAnalysisController（`/analysis/behavior`，6 端点）

```java
@RestController
@RequestMapping("/analysis/behavior")
public class BehaviorAnalysisController extends BaseController {

    @Autowired
    private UserBehaviorStatMapper userBehaviorStatMapper;

    /* 1. 流量入口分布（饼图+柱状图） */
    @GetMapping("/source")
    public R source(
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectByDimensionType("source", startDate, endDate));
    }

    /* 2. 行为趋势（折线图，按日期+行为类型） */
    @GetMapping("/trend")
    public R trend(
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectByDimensionType("behavior", startDate, endDate));
    }

    /* 3. 热搜关键词榜 */
    @GetMapping("/keywords")
    public R keywords(
        @RequestParam(required = false, defaultValue = "10") Integer limit,
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectTopByDimensionType("keyword", "pv", limit, startDate, endDate));
    }

    /* 4. 转化漏斗 */
    @GetMapping("/funnel")
    public R funnel(
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectByDimensionType("funnel", startDate, endDate));
    }

    /* 5. 时段热力图 */
    @GetMapping("/heatmap")
    public R heatmap(
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectByDimensionType("hour", startDate, endDate));
    }

    /* 6. 热门商品榜（浏览+加购+收藏合并，按pv排序） */
    @GetMapping("/topProducts")
    public R topProducts(
        @RequestParam(required = false, defaultValue = "10") Integer limit,
        @RequestParam(required = false) String startDate,
        @RequestParam(required = false) String endDate) {
        return R.ok().put("data", userBehaviorStatMapper.selectTopProducts(limit, startDate, endDate));
    }

    @ExceptionHandler(Exception.class)
    public void exceptionFallback(Exception e, HttpServletResponse resp) {
        e.printStackTrace();
        R.err(e).write(resp);
    }

    @Override
    protected FileTemplate getFileTemplate() { return null; }
}
```

## 六、Mapper 接口与 XML 设计

### 6.1 Mapper 接口（每个 4 个方法）

```java
package com.gec.dao;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.gec.domain.analysis.UserBehaviorStat;
import org.apache.ibatis.annotations.Param;
import java.util.List;

public interface UserBehaviorStatMapper extends BaseMapper<UserBehaviorStat> {

    /* 按 dimension_type 查询，支持日期范围过滤 */
    List<UserBehaviorStat> selectByDimensionType(
        @Param("dimensionType") String dimensionType,
        @Param("startDate") String startDate,
        @Param("endDate") String endDate);

    /* 按多个 dimension_type 查询（用于 return/keywords/topProducts 等） */
    List<UserBehaviorStat> selectByDimensionTypes(
        @Param("types") List<String> types,
        @Param("startDate") String startDate,
        @Param("endDate") String endDate);

    /* 按 dimension_type 查询 TOP N，按指定字段排序 */
    List<UserBehaviorStat> selectTopByDimensionType(
        @Param("dimensionType") String dimensionType,
        @Param("orderField") String orderField,
        @Param("limit") Integer limit,
        @Param("startDate") String startDate,
        @Param("endDate") String endDate);

    /* 热门商品榜（合并 product_view/product_cart/product_fav，按 pv 排序） */
    List<UserBehaviorStat> selectTopProducts(
        @Param("limit") Integer limit,
        @Param("startDate") String startDate,
        @Param("endDate") String endDate);
}
```

### 6.2 Mapper XML 示例（UserBehaviorStatMapper.xml）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.gec.dao.UserBehaviorStatMapper">

    <select id="selectByDimensionType" resultType="com.gec.domain.analysis.UserBehaviorStat">
        SELECT * FROM ads_user_behavior
        WHERE dimension_type = #{dimensionType}
        <if test="startDate != null and startDate != ''">
            AND stat_date &gt;= #{startDate}
        </if>
        <if test="endDate != null and endDate != ''">
            AND stat_date &lt;= #{endDate}
        </if>
        ORDER BY stat_date ASC, dimension_value ASC
    </select>

    <select id="selectByDimensionTypes" resultType="com.gec.domain.analysis.UserBehaviorStat">
        SELECT * FROM ads_user_behavior
        WHERE dimension_type IN
        <foreach collection="types" item="t" open="(" separator="," close=")">
            #{t}
        </foreach>
        <if test="startDate != null and startDate != ''">
            AND stat_date &gt;= #{startDate}
        </if>
        <if test="endDate != null and endDate != ''">
            AND stat_date &lt;= #{endDate}
        </if>
        ORDER BY stat_date ASC, dimension_type ASC, dimension_value ASC
    </select>

    <select id="selectTopByDimensionType" resultType="com.gec.domain.analysis.UserBehaviorStat">
        SELECT * FROM ads_user_behavior
        WHERE dimension_type = #{dimensionType}
        <if test="startDate != null and startDate != ''">
            AND stat_date &gt;= #{startDate}
        </if>
        <if test="endDate != null and endDate != ''">
            AND stat_date &lt;= #{endDate}
        </if>
        ORDER BY ${orderField} DESC
        LIMIT #{limit}
    </select>

    <select id="selectTopProducts" resultType="com.gec.domain.analysis.UserBehaviorStat">
        SELECT dimension_value AS product_id,
               SUM(pv) AS pv,
               SUM(uv) AS uv,
               SUM(conversion_count) AS conversion_count
        FROM ads_user_behavior
        WHERE dimension_type IN ('product_view', 'product_cart', 'product_fav')
        <if test="startDate != null and startDate != ''">
            AND stat_date &gt;= #{startDate}
        </if>
        <if test="endDate != null and endDate != ''">
            AND stat_date &lt;= #{endDate}
        </if>
        GROUP BY dimension_value
        ORDER BY pv DESC
        LIMIT #{limit}
    </select>
</mapper>
```

> **注意**：`selectTopProducts` 返回的字段不全（只有 product_id/pv/uv/conversion_count），MyBatis 会将未查询的字段设为 null。前端只取这几个字段即可。如果需要完整实体，可改为子查询或返回 Map。方案选择：**直接返回实体，缺省字段为 null**，课程作业可接受。

## 九、踩坑预防

1. **mapper-locations 子目录**：必须修改 application.yml 为 `classpath*:mappers/**/*.xml`，否则 analysis 子目录的 XML 不被扫描
2. **实体类字段名驼峰映射**：MyBatis-Plus 默认开启驼峰命名映射（map-underscore-to-camel-case=true），实体类用 `statDate` 对应数据库 `stat_date`，无需额外配置
3. **${orderField} SQL 注入**：`selectTopByDimensionType` 中 `ORDER BY ${orderField}` 用 `$` 而非 `#`，因为字段名不能用预编译参数。orderField 来自 Controller 硬编码（如 "pv"），无外部输入，安全。
4. **BaseController 抽象方法**：每个 Controller 必须实现 `getFileTemplate()` 返回 null（与 DashboardController 一致）
5. **@ExceptionHandler**：每个 Controller 都要有 `@ExceptionHandler(Exception.class)` 方法，调用 `R.err(e).write(resp)`（与现有 Controller 一致）
6. **日期参数格式**：前端传 `yyyy-MM-dd` 字符串，直接与数据库 `stat_date`（VARCHAR）比较，无需类型转换
7. **LIMIT 方言**：MySQL 支持 `LIMIT #{limit}`，无需分页插件
8. **Controller 包扫描**：`com.gec.controller.analysis` 是 `com.gec.controller` 的子包，Spring Boot 主类 `com.gec.MallAPP` 的组件扫描会自动包含，无需额外配置
