### 2.5 生成器技术约束

- 仅使用 JDK 自带类（`java.util.Random`、`java.io.*`、`java.time.*`），不引入第三方库

- 所有时间格式 `yyyy-MM-dd HH:mm:ss`
- 文件编码 UTF-8（用 `OutputStreamWriter` 指定 UTF-8）
- 生成完成后打印每个文件的路径和行数

## 四、交付物 3：MySQL 建表脚本

**文件路径**：`E:\space\Project\test\mall-sys\phase2_mysql_tables.sql`

4 张表，表名与 Hive ADS 层一致（`ads_user_behavior`、`ads_order_analysis`、`ads_review_analysis`、`ads_chat_analysis`）。

类型映射：
- STRING → VARCHAR(255)
- BIGINT → INT
- DECIMAL → 对应精度不变

额外要求：
- 每张表加 `id INT AUTO_INCREMENT PRIMARY KEY`（自增主键，不影响数据字段）
- 引擎 InnoDB，字符集 utf8mb4，排序 utf8mb4_general_ci
- 每张表加 `COMMENT` 说明用途
- 字段加 `COMMENT` 说明含义
