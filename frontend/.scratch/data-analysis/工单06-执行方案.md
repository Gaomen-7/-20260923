## 四、交付物 2：Java 落地程序 `MysqlLoader.java`

**文件路径**：`src/main/java/com/gec/loader/MysqlLoader.java`
**包名**：`com.gec.loader`（新建包）
**入口**：`public static void main(String[] args)`

### 4.1 设计要点

1. **独立运行**：不依赖 Spring 上下文，纯 JDBC 直连，main 方法可直接运行
2. **数据库连接**：硬编码连接参数（与 application.yml 一致），课程作业可接受
   - URL：`jdbc:mysql://localhost:3306/project20206?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true`
   - user：`root`，password：空字符串
3. **批量插入**：`PreparedStatement` + `addBatch`，每 1000 行 `executeBatch` 一次
4. **先清后写**：每张表先 `TRUNCATE TABLE`，再批量 INSERT（全量覆盖）
5. **CSV 解析**：用 `java.io.BufferedReader` 逐行读取，手动处理双引号包裹的字段（含逗号的字段）
6. **空值处理**：CSV 中空字符串对应 SQL NULL，用 `setNull` 或 `setObject(null)`
7. **打印统计**：每张表打印导入行数和耗时毫秒

### 4.4 CSV 解析注意事项

- Hive 导出的 CSV 用逗号分隔，**字段不含双引号**（因为 dimension_value 是中文类型名如"商品咨询"，不含逗号）

## 八、踩坑预防

1. **docker.exe 不在 PATH**：用完整路径 `C:\Program Files\Docker\Docker\resources\bin\docker.exe`，或先 `$env:Path += ";C:\Program Files\Docker\Docker\resources\bin"`
2. **MSYS 路径改写**：Git Bash 下 `docker exec ... -f /tmp/xxx.hql` 会被改写路径，需加 `MSYS_NO_PATHCONV=1` 前缀
3. **Hive LOCAL DIRECTORY 导出的是目录**：目录下文件名是 `000000_0`，不是 `.csv`，需要重命名
4. **MySQL driver 类名**：pom.xml 中用的是 `com.mysql.jdbc.Driver`（已废弃但可用），MysqlLoader 中用 `Class.forName("com.mysql.jdbc.Driver")` 或不写（JDBC 4.0 自动发现）
5. **空密码连接**：MySQL root 无密码，`DriverManager.getConnection(url, "root", "")` 即可
6. **TRUNCATE 外键约束**：4 张表无外键关联，TRUNCATE 不会报错
7. **CSV 最后一行无换行符**：BufferedReader.readLine() 仍能正常读取最后一行
8. **serverTimezone**：JDBC URL 必须加 `serverTimezone=Asia/Shanghai`，否则 MySQL 8 会报时区错误
