# 电商数据分析（第二阶段）

基于 Hadoop + Hive + MySQL + SpringBoot + Vue + ECharts 的电商用户行为与销售数据离线分析平台。从模拟原始数据出发，经 Hive 清洗聚合后落地 MySQL，最终以可视化看板呈现。

## 语言

### 数据源

**行为日志（Behavior Log）**：
用户在电商平台的操作记录，包括浏览、搜索、加购、收藏、下单、支付等 7 类行为。每行一条记录，含用户ID、商品ID、行为类型、时间戳、渠道等字段。
_Avoid_：点击流、用户轨迹

**订单数据（Order Data）**：
订单主表与订单明细的结构化交易数据，含订单状态、实付金额、退换货状态等。
_Avoid_：交易记录、销售流水

**评价数据（Review Data）**：
用户对商品的评价内容，含评分（好/中/差）、评价文本、追评、评价时间。
_Avoid_：评论、口碑

**交流数据（Chat Data）**：
用户与商家客服的会话记录，含咨询类型、会话时长、是否转化。
_Avoid_：客服记录、咨询日志

### 数据处理层

**数据生成器（Data Generator）**：
Java 程序，模拟生成上述 4 类原始数据文件，输出到本地目录。匹配第一阶段 Java 技术栈。
_Avoid_：数据模拟器、造数脚本

**ODS 层（Operational Data Store）**：
Hive 中的原始数据落地层，表名前缀 `ods_`，4 张表对应 4 类数据源，结构与原始文件一致，不做清洗。
_Avoid_：原始层、贴源层

**ADS 层（Application Data Store）**：
Hive 中的应用结果层，表名前缀 `ads_`，4 张宽表对应 4 个分析模块，直接供 MySQL 落地使用。
_Avoid_：结果层、应用层、汇总层

**CSV 中转（CSV Bridge）**：
Hive 查询结果导出为 CSV 文件，Java 程序读取 CSV 写入 MySQL 的中转环节。替代 Sqoop，减少工具依赖。
_Avoid_：数据导出、ETL 中转

**宽表（Wide Table）**：
每个分析模块一张 MySQL 表，包含该模块所有可视化指标，按查询维度冗余存储，不做星型建模。
_Avoid_：事实表、聚合表

### 分析模块

**用户全链路行为分析**：
模块①，分析用户从入口到转化的完整行为路径，含行为分布、趋势、转化漏斗、时段热力、热门榜单。

**用户订单数据分析**：
模块②，分析订单与销售数据，含销售指标、趋势、品类分布、退换货、客单价。

**用户评价数据分析**：
模块③，分析商品评价，含评价概览、等级分布、情感关键词、品类口碑对比、趋势。

**用户与商家交流分析**：
模块④，分析客服会话，含会话概览、咨询类型、时段热力、转化、热门商品。
