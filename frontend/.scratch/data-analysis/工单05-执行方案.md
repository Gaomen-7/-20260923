## 三、清洗规则

### 3.1 无效过滤（在临时表中完成）

1. `session_id IS NULL OR session_id = ''` → 剔除
2. `CAST(user_msg_count AS INT) = 0` → 剔除
3. `CAST(session_duration_sec AS INT) < 5` → 剔除（秒退会话）
4. `CAST(user_msg_count AS INT) = 1 AND CAST(merchant_reply_count AS INT) = 0` → 剔除（纯表情包/无有效内容）

### 3.2 字段规整

- `stat_date = TO_DATE(chat_start_time)`
- `chat_hour = HOUR(chat_start_time)`（0-23）
- 数值字段统一 CAST 为 INT
- `first_response_sec > 3600` 的视为异常值，计算 `avg_first_response` 时排除（用 NULLIF + CASE WHEN）

### 3.3 指标定义（验收标准）

- **问题解决率** `resolution_rate` = `merchant_reply_count >= 1` 的会话数 / 总会话数
- **咨询转化率** `conversion_rate` = `is_converted = 1` 的会话数 / 总会话数
- **无效咨询占比** `invalid_rate` = `merchant_reply_count = 0` 的会话数 / 总会话数
- **平均首次响应**：仅统计 `first_response_sec > 0 AND first_response_sec <= 3600` 的记录

## 五、各查询详细字段映射

### 查询1：overview（会话总览）

```
stat_date = 清洗后 stat_date
dimension_type = 'overview'
dimension_value = 'all'
session_count = COUNT(*)
user_count = COUNT(DISTINCT user_id)
avg_duration = AVG(CAST(session_duration_sec AS INT))
avg_first_response = AVG(CASE WHEN first_response_sec > 0 AND first_response_sec <= 3600 THEN first_response_sec ELSE NULL END)
avg_reply_count = AVG(CAST(merchant_reply_count AS INT))
resolution_rate = SUM(CASE WHEN merchant_reply_count >= 1 THEN 1 ELSE 0 END) / COUNT(*)
conversion_count = SUM(CASE WHEN is_converted = '1' THEN 1 ELSE 0 END)
conversion_rate = conversion_count / COUNT(*)
invalid_rate = SUM(CASE WHEN merchant_reply_count = 0 THEN 1 ELSE 0 END) / COUNT(*)
GROUP BY stat_date
```

### 查询2：chat_type（咨询类型分布）

```
dimension_type = 'chat_type'
dimension_value = chat_type
session_count = COUNT(*)
user_count = COUNT(DISTINCT user_id)
avg_duration / avg_first_response / avg_reply_count / resolution_rate 同查询1
conversion_count / conversion_rate 同查询1
invalid_rate = 该类型中 merchant_reply_count=0 的占比
GROUP BY stat_date, chat_type
```
> 占比字段：如需"该类型占当日总会话比例"，可额外用 conversion_rate 列复用，但建议保持 conversion_rate 为实际转化率。

### 查询3：hour（时段热力）

```
dimension_type = 'hour'
dimension_value = CAST(chat_hour AS STRING) （0-23）
session_count = COUNT(*)
user_count = COUNT(DISTINCT user_id)
avg_duration = AVG(session_duration_sec)
其余指标填 NULL（时段热力只需会话数和用户数）
GROUP BY stat_date, chat_hour
```

### 查询4：conversion（咨询转化）

```
dimension_type = 'conversion'
dimension_value = chat_type
session_count = COUNT(*)
user_count = COUNT(DISTINCT user_id)
conversion_count = SUM(CASE WHEN is_converted='1' THEN 1 ELSE 0 END)
conversion_rate = conversion_count / session_count
avg_duration 填 NULL
-- 额外：用 avg_first_response 列复用为"加购数"，avg_reply_count 列复用为"下单数"
-- 即：avg_first_response = CAST(SUM(CASE WHEN convert_action='加购' THEN 1 ELSE 0 END) AS DECIMAL(10,2))
--     avg_reply_count = CAST(SUM(CASE WHEN convert_action='下单' THEN 1 ELSE 0 END) AS DECIMAL(5,2))
resolution_rate / invalid_rate 填 NULL
GROUP BY stat_date, chat_type
```

### 查询5：product（热门咨询商品 TOP20）

```
dimension_type = 'product'
dimension_value = product_id
session_count = COUNT(*)

conversion_count = SUM(CASE WHEN is_converted='1' THEN 1 ELSE 0 END)

其余指标正常计算
```

## 六、临时表设计

### tmp_clean_chat

```sql
CREATE TEMPORARY TABLE tmp_clean_chat AS
SELECT
  chat_id,
  user_id,
  product_id,
  category_id,
  session_id,
  chat_type,
  CAST(user_msg_count AS INT) AS user_msg_count,
  CAST(merchant_reply_count AS INT) AS merchant_reply_count,
  CAST(first_response_sec AS INT) AS first_response_sec,
  CAST(session_duration_sec AS INT) AS session_duration_sec,
  CAST(is_converted AS INT) AS is_converted,
  convert_action,
  chat_start_time,
  TO_DATE(chat_start_time) AS stat_date,
  HOUR(chat_start_time) AS chat_hour
FROM ods_chat_data
WHERE session_id IS NOT NULL AND session_id != ''
  AND CAST(user_msg_count AS INT) > 0
  AND CAST(session_duration_sec AS INT) >= 5
  AND NOT (CAST(user_msg_count AS INT) = 1 AND CAST(merchant_reply_count AS INT) = 0);
```

### tmp_daily_total

```sql
CREATE TEMPORARY TABLE tmp_daily_total AS
SELECT stat_date, COUNT(*) AS total_cnt
FROM tmp_clean_chat
GROUP BY stat_date;
```

## 七、踩坑预防（继承自工单02/03/04）

1. **防OOM**：脚本头部必须加 `SET io.sort.mb=32;`（工单03 HS2 OOM 经验）
2. **中文匹配**：JVM 已设置 `file.encoding=UTF-8`，chat_type 中文字符串可直接用 `=` 匹配，无需额外处理
3. **占比分母**：避免相关子查询，用 `tmp_daily_total` JOIN 实现（工单04经验）
4. **NULL 处理**：除法用 `NULLIF(denominator, 0)` 防止除零
5. **DECIMAL 精度**：率类字段统一 `CAST(... AS DECIMAL(5,4))`，时长类 `DECIMAL(10,2)`，回复次数 `DECIMAL(5,2)`
6. **LIMIT 全局截断**：product TOP20 是全局截断（非每日），与工单04 keyword 处理一致
7. **first_response_sec 异常值**：`> 3600` 的在 AVG 时用 `CASE WHEN ... ELSE NULL END` 排除，AVG 自动忽略 NULL
