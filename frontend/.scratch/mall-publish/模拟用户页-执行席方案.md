## 一、需求复述与可行性结论

- 导航栏新增「模拟用户」页面。
- 页面**左侧**：模拟商城前台 —— 展示商品卡片，用户可点击「浏览 / 收藏 / 加购 / 购买」，顶部可输入关键词模拟搜索。
- 页面**右侧**：经典命令行风格的日志终端（黑底等宽字体），左侧每发生一个行为，右侧终端实时滚动追加一行带时间戳的彩色日志。
- 可行性：✅ 可行。全部为前端状态驱动，商品数据复用现有 `GET /Goods/list` 接口，日志为前端内存数组，无新增依赖、无新接口、无建表。

---

## 二、技术决策（已定案，勿改）

| 决策点 | 结论 |
|---|---|
| 是否动后端 | **否**。仅前端新增 1 个 .vue + 改路由 + 改 App.vue |
| 商品数据来源 | `getGoodsList({page:1, limit:12, publishStatus:1})`，取真实上架商品；接口失败时用内置 8 条演示商品兜底 |
| 日志存储 | 组件内 `logs` 数组（上限 500 行，超出 shift），不落库 |
| 行为类型 | 浏览 / 搜索 / 收藏 / 加购 / 购买 / 支付（与第二阶段 Hive ods_user_behavior 的 behavior_type 对齐） |
| 新依赖 | **无**。只用现有 axios + element-ui + 原生 CSS |
| 路由 | `/simulate/user`，懒加载 |
| 导航位置 | 「数据分析」分组下第一个，P=25，多巴胺青 `--dop-cyan` 图标 |
| 代码规范 | webpack3 + babel6：**禁用可选链 `?.`、禁用 async/await**，统一用 `.then()` 链；字符串拼接用 `+`；箭头函数可用 |

## 六、SimulateUser.vue 实现规格

### 6.1 页面整体布局

根元素 `.sim-page`，CSS Grid 两列：左 `1fr`、右 `560px`，gap 16px，高度 `calc(100vh - 140px)`（顶栏 68px + body padding 48px 留余量），**两列各自内部滚动，页面本身不滚动**。

```
┌────────────────────────────────────────────────────────────┐
│ 左：模拟商城前台                    │ 右：user-behavior.log │
│ ┌──────────────────────────────────┐ │ ┌───────────────────┐ │
│ │ 顶栏：标题 + 搜索框 + 用户芯片    │ │ │ ●●● 标题栏+控制按钮 │ │
│ ├──────────────────────────────────┤ │ ├───────────────────┤ │
│ │ 商品网格 3 列，卡片               │ │ │                   │ │
│ │  [图] 名称 ￥价格                 │ │ │   黑底终端，逐行   │ │
│ │  [浏览][收藏][加购][购买]         │ │ │   彩色日志自动滚动 │ │
│ │  ...                            │ │ │                   │ │
│ ├──────────────────────────────────┤ │ │   ▌(闪烁光标)      │ │

│ └──────────────────────────────────┘ │                       │
└────────────────────────────────────────────────────────────┘
```

### 6.2 data 字段

```js
data() {
  return {
    goodsList: [],
    searchKeyword: '',
    userId: 'u_' + Math.floor(10000 + Math.random() * 89999),
    sessionId: 's_' + Date.now().toString(36),
    deviceType: ['iPhone15', 'Android14', 'WindowsPC', 'MacBook'][Math.floor(Math.random()*4)],
    city: ['北京','上海','深圳','杭州','广州'][Math.floor(Math.random()*5)],
    favorites: [],          // 收藏的 goodsId 数组

    logs: [],               // {time, level, text}
    autoMode: false,
    autoTimer: null,
    logBox: null            // this.$refs.logBox，滚动用
  }
}
```

### 6.4 方法清单（必须全部实现）

| 方法 | 行为 |
|---|---|
| `loadGoods()` | `getGoodsList({page:1, limit:12, publishStatus:1}).then(resp=>{ this.goodsList = (resp.data||[]).slice(0,12) }).catch(()=>{ this.goodsList = DEMO_GOODS })`；数据回来后调 `bootLogs()` |
| `bootLogs()` | 追加 3 行启动日志（见 6.6） |
| `pushLog(level, text)` | `this.logs.push({time: this.fmtTime(new Date()), level: level, text: text})`；`if(this.logs.length>500) this.logs.shift()`；`this.$nextTick(()=>{ this.$refs.logBox.scrollTop = this.$refs.logBox.scrollHeight })` |
| `fmtTime(d)` | 返回 `HH:mm:ss`，手动补零 |
| `handleView(g)` | `pushLog('view', '浏览商品 '+g.goods_name+' (id='+g.id+') ￥'+g.price)`；卡片加短暂高亮（用 CSS class flash，200ms 后移除，简单实现即可） |
| `handleFav(g)` | 切换 favorites 数组；pushLog('fav', 收藏/取消收藏 商品名) |
| `handleAddCart(g)` | `this.cart[g.id] = (this.cart[g.id]||0)+1`；pushLog('cart', '加入购物车 '+g.goods_name+' 数量='+this.cart[g.id]+' 单价￥'+g.price) |
| `handleBuy(g)` | `pushLog('buy', '提交订单 '+g.goods_name+' ￥'+g.price)`；`setTimeout(()=>this.pushLog('pay','支付成功 订单金额￥'+g.price), 400)` |
| `handleSearch()` | 若 searchKeyword 非空：`pushLog('search', '搜索关键词「'+this.searchKeyword+'」')`；清空输入 |
| `clearLogs()` | `this.logs = []` |
| `exportLogs()` | 把 logs 拼成文本（每行 `time level text`），用 Blob + a 标签下载 `user-behavior.log.txt` |
| `toggleAuto()` | autoMode 取反；开：`this.autoTimer = setInterval(()=>{随机挑 goodsList 里一个商品，随机执行 view/cart/fav 之一}, 900)`；关：`clearInterval` |
| `beforeDestroy()` | `clearInterval(this.autoTimer)` |

**购物车数量 computed**：`cartCount(){ var n=0; for(var k in this.cart){ n+=this.cart[k] } return n }`。

### 6.5 左侧商品卡片规格

- 图片位：无真实图也没关系，用 CSS 渐变方块 + 商品名首字占位（24px 圆角，多巴胺色循环）。
- 价格：红色加粗 `￥{{ g.price }}`。
- 按钮组 4 个 `el-button size="mini"`：浏览(默认)、收藏(warning，已收藏变 success)、加购(primary)、购买(success)。
- 收藏态用 `favorites.indexOf(g.id)>-1` 判断。

### 6.6 终端日志样式规则（level → 颜色）

| level | 中文含义 | 颜色 |
|---|---|---|
| `boot` | 系统启动 | `#58a6ff` 蓝 |
| `view` | 浏览 | `#8b949e` 灰 |
| `search` | 搜索 | `#d2a8ff` 紫 |
| `fav` | 收藏 | `#e3b341` 黄 |
| `cart` | 加购 | `#39d2c0` 青 |
| `buy` | 购买 | `#7ee787` 绿 |
| `pay` | 支付 | `#3fb950` 亮绿 |

启动日志示例：
```
[boot] 会话建立 session=s_xxx device=iPhone15 city=深圳
[boot] 用户 u_12345 进入商城前台
[boot] 加载推荐商品 12 件
```

终端容器：背景 `#0d1117`，圆角 12px，内边距 16px，字体 `Consolas, Monaco, monospace`，字号 13px，行高 1.7，`overflow-y:auto`。标题栏仿 macOS：左侧 3 个圆点（#ff5f57/#febc2e/#28c840），中间标题 `user-behavior.log — live`，右侧 3 个小按钮：清空 / 导出 / 自动模拟（el-switch）。末尾画一个闪烁光标 `▌`（CSS animation 1s steps(1) infinite）。

### 6.7 禁止事项（webpack3 红线）

1. **禁止 `?.`**，写成 `this.cart && this.cart[g.id]`。
2. **禁止 async/await**，用 `.then()`。
3. **禁止 `npm install` 任何新包**。
4. 不要改 request.js、不要动其他组件。
