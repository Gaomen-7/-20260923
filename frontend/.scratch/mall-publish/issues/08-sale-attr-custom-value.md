# 08 — 销售属性"+自定义"交互

**What to build:** 在销售属性设置页，用户可以为每个销售属性添加标准模板之外的自定义值（如标准颜色只有黑/白，用户可添加"红色"），自定义值自动选中并参与后续SKU笛卡尔积生成。

**Blocked by:** 03 — 前端SKU设置页（自定义值需要能传递到SKU生成流程；实际可与03并行开发UI，但联调在03之后）

**Status:** ready-for-agent

- [ ] SetSaleAttr.vue 中每个销售属性行的复选框组末尾添加"+自定义"按钮（el-button type="text"）
- [ ] 点击"+自定义"弹出 el-input 输入框（内联或小型弹窗），用户输入自定义值后按回车或点击确认
- [ ] 自定义值校验：非空、不与该属性已有值（标准值+已自定义值）重复，重复时提示"该值已存在"
- [ ] 自定义值添加后：自动追加到该属性的选中值列表中，自动选中（checkbox checked），在UI上以特殊样式标记（如标签右上角有"自定义"角标或不同颜色）
- [ ] 自定义值可删除：自定义值的标签旁有×删除按钮，删除后从选中值列表移除
- [ ] 保存时：自定义值随 attrList 一起提交到后端（saveSaleAttrValues），后端原样存入Redis，不写入 tbl_goods_attr 模板表
- [ ] SKU生成时：自定义值作为选中值的一部分参与笛卡尔积（02的generateSku接口无需修改，因为它只处理传入的选中值列表）
- [ ] 验证：在销售属性页为颜色属性添加自定义值"红色" → 自动选中 → 保存 → 进入SKU页 → 生成的SKU中包含"红色"的组合行
