# 删除前端导航栏"销售统计"和"销售策略"菜单项

## 任务

删除 `D:\vue-space\mypro5\src\App.vue` 导航栏中的"销售统计"和"销售策略"两个菜单项。

## 修改文件

仅修改一个文件：`D:\vue-space\mypro5\src\App.vue`

## 具体修改

删除第 66-71 行的两个 `<td>` 元素（销售统计和销售策略）：

```html
				<td @click="select(13)">
					<a href="#/BBB" :style="{color:(P==13?ON:OFF)}">销售统计</a>
				</td>
				<td @click="select(14)">
					<a href="#/.." :style="{color:(P==14?ON:OFF)}">销售策略</a>
				</td>
```

删除后，"客服交流"（第63-65行）后面直接接"退出系统"（第72-74行）。

## 注意事项

1. 这两个菜单项的链接都是无效占位链接（`#/BBB` 和 `#/..`），删除后不影响任何已有功能
2. 只删除这两个 `<td>`，不要改动其他导航项
3. 删除后运行 `npm run build` 确认编译通过
4. 缩进保持与周围代码一致（使用 Tab 缩进）
