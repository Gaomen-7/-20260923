## 三、Standards 轴依据

### 仓库成文规范（见交接文档"已知问题"章节）

1. **webpack3 + babel6，禁用 ES2018+ 语法**：不得出现 `?.`（用 `&&` 或三元替代）、不得用 `async/await`；本次 hunks 中 `||`、三元、普通函数均合规，需逐处复核无 `?.` 混入。
2. **依赖锁定**：不得 `npm install xxx@latest`；本次无新依赖（`<img>` 原生标签，未引新组件），需确认。
3. **URL 拼接惯例**：现有页面用 `BASE = "http://localhost:8090/mall-sys"` 字面量（Brand.vue L135、Category.vue L260、PublishBaseInfo.vue L244、SetSku.vue L176）——本次 coverBase 与之一致，但注意 axios 实例 `request.js` 已有 baseURL，图片 URL 走绝对地址是历史惯例，不算新问题。
4. **字段命名**：后端 JSON 为 camelCase（goodsName/brandName/logoUrl），前端列表模板已按此对齐。

### Fowler 坏味道基线（全文照抄，逐条对 hunks 判断）

- **Mysterious Name** — 名字看不出意图 → 本次 `coverBase` 命名清晰，重点查归一化 map 里的别名 `goods_name`。
- **Duplicated Code** — 同一逻辑形状在多处重复 → **重点**：`coverBase` 同一字面量已出现在 GoodsManage + SimulateUser 两处；`BASE=http://localhost:8090/mall-sys` 在 5+ 文件重复。
- **Feature Envy** — 方法摸别人数据多过自己的 → 本次无类，主要看组件内函数。
- **Data Clumps** — 几个字段总一起出现 → goods_name/price/mainImage 是否值得一个 view model。
- **Primitive Obsession** — 字符串/原始值冒充领域概念 → 图片 URL 拼接字符串散落各处。
- **Repeated Switches** — 同一类型 switch/if 反复出现 → 本次无。
- **Shotgun Surgery** — 一个逻辑改动要散改多处 → **重点**：camelCase/snake_case 字段不一致问题，SimulateUser 修了归一化，其他页面是否还有同类隐患。
- **Divergent Change** — 一个文件为不相关原因被改 → 本次每文件单一目的，应通过。
- **Speculative Generality** — 加了 spec 没有的抽象 → 归一化 map 同时兼容 `goods_name/main_image` 下划线写法，属于"防御不存在的旧格式"，判断是否过度。
- **Message Chains / Middle Man / Refused Bequest** — 本次无类继承结构，跳过。

> 成文规范优先于基线；基线坏味道一律为"判断项"，不是硬违规。
