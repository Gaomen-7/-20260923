### 3.3 UserServiceImpl.java — 实现 login

**文件**：`E:\space\Project\test\mall-sys\src\main\java\com\gec\service\impl\UserServiceImpl.java`

添加 login 方法实现：
```java
@Override
public User login(String account, String password) {
    // 1. 按账号查询用户
    User user = lambdaQuery().eq(User::getAccount, account).one();
    if (user == null) {
        throw new RuntimeException("账号不存在");
    }
    // 2. 密码为空的用户不允许登录
    if (user.getPassword() == null || user.getPassword().isEmpty()) {
        throw new RuntimeException("该账号未设置密码，请联系管理员");
    }
    // 3. BCrypt 密码校验
    org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder encoder =
        new org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder();
    if (!encoder.matches(password, user.getPassword())) {
        throw new RuntimeException("账号或密码错误");
    }
    return user;
}
```

> 若编译报错找不到 BCryptPasswordEncoder（说明无 spring-security-crypto 依赖），则改为明文比对（课程作业可接受）：
> ```java
> if (!user.getPassword().equals(password)) {
>     throw new RuntimeException("账号或密码错误");
> }
> ```
> 同时需要把数据库中 admin 的密码改为明文，见第六节。

### 3.4 UserController.java — 添加 login 端点

**文件**：`E:\space\Project\test\mall-sys\src\main\java\com\gec\controller\UserController.java`

在类中添加（放在 list 方法之前）：
```java
/* 登录接口 */
@PostMapping(
        value="/login",
        produces="application/json;charset=UTF-8"
)
public R login(@RequestBody Map map){
    try{
        String account = (String) map.get("account");
        String password = (String) map.get("password");
        User user = userService.login(account, password);
        // 生成简单 token（UUID，课程作业级别，不做 JWT）
        String token = java.util.UUID.randomUUID().toString().replace("-", "");
        // 密码不返回给前端
        user.setPassword(null);
        return R.ok().put("token", token).put("user", user);
    } catch(Exception e){
        e.printStackTrace();
        return R.err(e);
    }
}
```

> 登录成功响应格式：`{result:"success", status:200, token:"xxx", user:{id,account,nickName,...}}`

### 4.3 router/index.js — 添加 login 路由 + 路由守卫

**文件**：`D:\vue-space\mypro5\src\router\index.js`

**步骤 A**：在 import 区域添加：
```javascript
import Login from '@/components/Login'
```

**步骤 B**：在 routes 数组最前面添加：
```javascript
{
  path: '/login',
  name: 'login',
  component: Login
},
```

**步骤 C**：在 `export default new Router({...})` 之后，添加路由守卫：

将原来的：
```javascript
export default new Router({
  routes: [...]
})
```

改为：
```javascript
const router = new Router({
  routes: [...]
})

// 全局路由守卫：未登录跳转登录页
router.beforeEach((to, from, next) => {
  let token = window.sessionStorage.getItem('token')
  if (to.path === '/login') {
    next()
  } else if (!token) {
    next('/login')
  } else {
    next()
  }
})

export default router
```

> 注意：原来的 `export default new Router({...})` 必须拆成 `const router = ...` + `export default router`，否则无法挂载 beforeEach。

## 五、数据库准备（确保可登录账号）

执行席完成代码修改后，需确保 admin 账号密码可登录。

**如果后端用 BCrypt 校验**：现有 admin 密码哈希 `$2a$10$NfjVFlsrx9s575T39vS85.QFkRQI2lf8agq1ptqjfleDCwZFqf16i` 对应的明文需确认。执行以下 SQL 将 admin 密码重置为已知 BCrypt 值（123456 的 BCrypt）：

```sql
USE project20206;
UPDATE tbl_user SET password='$2a$10$NfjVFlsrx9s575T39vS85.QFkRQI2lf8agq1ptqjfleDCwZFqf16i' WHERE account='admin';
```

> 上述哈希值是现有值，若对应明文不是 123456，则用以下 Java 生成新哈希：
> `new BCryptPasswordEncoder().encode("123456")`，然后用生成的值 UPDATE。

**如果后端用明文比对**（无 spring-security-crypto 依赖时）：
```sql
USE project20206;
UPDATE tbl_user SET password='123456' WHERE account='admin';
```

## 七、注意事项

1. **webpack3 约束**：Login.vue 中不要用可选链 `?.`、对象展开运算符 `...`（除了 Vue 模板里的 `...`）、async/await。用普通函数和 `&&` 代替。
2. **el-input 的 prefix-icon**：element-ui 2.15.14 支持，无需额外配置。
3. **路由守卫拆分**：router/index.js 必须把 `export default new Router()` 拆成 `const router = ...` + `export default router`，这是最容易出错的点。
4. **App.vue 导航栏 v-if**：只给导航栏那个 div 加 v-if，`<router-view/>` 不要加（登录页也需要 router-view 渲染）。
5. **token 存储**：用 sessionStorage（request.js 已从 sessionStorage 取 token），不要用 localStorage。
6. **密码不返回**：login 接口中 `user.setPassword(null)` 必须执行，避免密码哈希泄露到前端。
7. **后端重启**：Java 代码修改后必须在 IDEA 中重启 MallAPP，否则新接口不生效。
8. **UserBO 不含 password**：已确认 UserBO 是独立 BO 类（不继承 User），用户列表接口不会返回密码字段，无需额外处理。
