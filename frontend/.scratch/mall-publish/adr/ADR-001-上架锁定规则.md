# ADR-001: 商品上架锁定规则

## 状态

已采纳

## 背景

电商平台中，商品上架后如果允许随意修改核心信息（名称/价格/规格），
可能导致已下单用户收到的商品与描述不符，引发销售纠纷。

## 决策

1. 商品上架后（publish_status=1），核心信息锁定，不可编辑
2. 下架后（publish_status=0）可编辑，编辑后需重新上架
3. 允许二次上架，无需审核（课程作业级别简化）
4. 前端按钮层面禁用 + 后端接口层面校验，双重保障

## 后果

- 正面：避免销售纠纷，数据一致性有保障
- 负面：商家修改信息需要先下架，可能短暂影响销售
- 后续优化：可增加"审核中"状态，下架修改后需审核通过才能上架
